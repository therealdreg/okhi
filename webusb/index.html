                    Link benchmark
                    

                        
                        
                        
                        
                        
                        
                        
                    

                    
                    
                    
Climbs the SPI clock to bracket the ceiling, halves the bracket down to 1 MHz,
                        then hammers the winner for the confirmation time to prove it does not drop a single frame in
                        either direction. If the confirmation fails it drops a megahertz and tries again. A 250 ms
                        step only screens; the confirmation is the number worth trusting.

                    
The PL022 only divides clk_peri by an even number, so reaching every megahertz
                        means moving clk_peri, and above the stock rate that means reprogramming the USB PLL. That is
                        free here because nothing else uses it. Every result says which clock recipe produced it, and
                        the clock tree is put back on every exit path. Keystroke capture is suspended for the WHOLE
                        run.

                    
On UART the two chips step through the standard baud rates together, agreeing on
                        the next one over SPI so a rate that breaks the line cannot take the run with it. The slowest
                        and fastest pickers, the overclock and the refinement do not apply there. That port is also
                        the ESP console, so its logging is silenced while the test runs.

                    

                    

                    

                    

                    

                    

                

            

            

                

                    Hardware self test
                    
Looks for a board that was assembled badly rather than for a bug: a joint that
                        never wetted, a bridge between two pads, a part sitting at an angle. Every check reports the
                        numbers it measured and names the part or the net to go and inspect, so an intermittent board
                        can be told apart from a dead one.

                    
                    
                    
                    

                    

                    

                    

                

            

            

                

                    Network
                    

                    

                        
                    

                    
                    
                    
                    
                    
                    
In access point mode the device makes its own network and the name above is
                        ignored. Joining one is how it becomes reachable from your LAN. Either way the device reboots
                        to apply it and you will have to reconnect.

                    
If it cannot join the network twice in a row it comes back as an access point on
                        its own, with the setting still on record, so a typo cannot lock you out. Flashing any
                        different firmware wipes this and everything else stored, by design.

                    

                

            

            

                
                
Reboots the RP2040, which pulls the ESP down with it, so the whole board restarts.
                    RESET TIMES below counts every restart since the last flash, so a click that makes it climb is
                    proof the board actually rebooted. The page reconnects on its own once it is back.
